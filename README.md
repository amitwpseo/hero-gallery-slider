# hero-gallery-slider

An interactive accordion-style hero image gallery slider featuring dynamic text overlays and navigation controls.

## Overview

This single-file web application displays a full-viewport hero section with 10 image panels. Browsing through the gallery updates a central editorial text overlay displaying details about each item.

## Features

- **Accordion Panels**: 10 vertical panels with staggered initial heights that expand and reveal color on hover or click.
- **Dynamic Text Overlay**: Animated text transitions that update the active category, title, and description based on the selected panel.
- **Navigation Controls**: Includes Next and Previous buttons to cycle through gallery items sequentially.
- **Responsive Design**: Includes basic media query adjustments for smaller screens.
- **Zero Dependencies**: Constructed using native HTML, CSS, and plain JavaScript.

## Getting Started

Open `index.html` in any modern web browser to view and interact with the hero gallery.
